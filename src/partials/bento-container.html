Bento Grid

Tiles of different sizes on one row rhythm - the layout a services page or a dashboard reaches for when a plain grid makes every item look equally important. One column on a phone, two from sm, four from lg. mw-bento-wide spans two columns, -tall two rows, -lg both and -full the whole row. Spans only start with the second column, so a phone gets a plain stack at content height. The grid packs dense, which can move a later tile into an earlier gap - keep the tile order the reading order.
