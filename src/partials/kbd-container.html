Keyboard Keys

Anything that tells someone which key to press should look like the key. <kbd> is styled directly, so a shortcut in prose needs no class at all; mw-kbd is there for a span when the markup is not yours to change.

In prose

Press Ctrl+Shift+P to open the command palette, Esc to close it and Enter to run the selection.

On a Mac that is ⌘+⇧+P.

Held down

Space shown mid-press - the raised edge drops and the key sits 1px lower, for a hint that demonstrates rather than lists.
